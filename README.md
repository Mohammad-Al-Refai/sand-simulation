### Sand simulation

https://github.com/user-attachments/assets/ae837dd8-a842-4e25-b6d9-4c83c3192252

### Requirements

- [Go](https://go.dev/dl/) 1.26.2 or later

### Run

```bash
go run .
```

### Build for web

```bash
go run ./tools/buildweb
```

### Controls

- Key `1` for Sand
- Key `2` for Water
- Key `3` for Wall
- Left mouse to draw
- Right mouse to clear
- Key `R` to reset
- `Esc` to quit
